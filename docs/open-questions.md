# 열린 질문과 가정

정본에 없어서 구현자가 임시로 정한 항목을 한 줄씩 기록한다.

형식: 항목 / 정한 임시값 / 이유

| 항목 | 임시값 | 이유 |
|---|---|---|
| 1단계 도시 | 서울, 도쿄, 뉴욕 (`src/data/cities.json`, 소개 문구는 임시) | 명세 11절 [가정]을 그대로 따름 |
| 스탯 항목 | 체력·공격·방어·속도 4개. 역할별 1레벨 기본값과 레벨당 증가량 (`src/data/stats.json`) | 명세 2절 [가정]. 전투에 필요한 최소 항목 |
| 피해 공식 | 공격 × 스킬 위력 × 100/(100+방어) × 상성 × 구성 × 열 약점 × 분산(0.9~1.1), 최소 1 (`combat.json`) | 정본에 공식 없음. 방어가 커져도 피해가 0이 되지 않는 형태 |
| 반대 열 약점 크기 | 기본 위치가 아닌 열에 두면 주는 피해 ×0.85, 받는 피해 ×1.15 | 명세 5절 [제안]. "약점이 생긴다"만 있어 양쪽에 걸었음 |
| 구성 보너스 계산 | 전위·딜러·지원 중 있는 분류마다 +5%, 없는 분류마다 −10%를 더함(셋 다 +15%, 하나 없으면 0%, 둘 없으면 −15%) | 명세 5절 문장을 이렇게 해석 |
| 구성 보너스 적용 대상 | 플레이어 파티에만 적용, 몬스터 무리는 1.0 (`composition.appliesToSides`) | 명세가 "파티 구성"이라고만 함. 데이터 한 줄로 몬스터에도 켤 수 있음 |
| 역할 분류 | 방패·전사=전위, 사수·술사=딜러, 치유사·지휘관=지원. (비활성) 암습자=기동, 교란자=지원 | 명세 4절 구분 열을 구성 판정 분류로 씀 |
| 도발 범위 | 단일 대상 공격만 끌어옴. 열 공격·범위 공격은 영향 없음. 지속 2라운드, 쿨다운 3 | 명세 5절 [제안]에 범위 공격과의 관계가 없음 |
| 스킬 목록 | 역할마다 기본 공격 1 + 스킬 2, 총 18개 (`skills.json`). 이름·위력·쿨다운 임시 | 명세 5절 "역할이 정하는 틀"에 맞춰 최소 구성 |
| 쿨다운 의미 | 쿨다운 N = 자기 턴 N번에 한 번 사용. 첫 라운드부터 사용 가능 | 정본에 세부 없음 |
| 행동 방식(AI) | 스킬 1 → 스킬 2 → 기본 공격 순으로 쓸 수 있고 쓸모 있는 것. 치유는 체력 70% 미만 아군이 있을 때만 | 1단계 'default' 하나. 대상은 시드로 고름 |
| 상태 지속 | 버프·도발은 걸린 라운드 포함 N라운드, 라운드 끝에 1씩 감소 | 정본에 세부 없음 |
| 경상·중상 판정 | 쓰러진 용병마다 중상 확률: 승리 20%, 철수 40%, 패배 60%. 일수는 각 범위 안 균등 | 명세 6절에 경상/중상 가르는 기준이 없음 |
| 치유사 부상 감소 조건 | 파티에 치유사가 있으면 그 치유사가 쓰러졌어도 적용 | 명세 6절 "파티에 치유사가 있으면" 문구를 그대로 따름 |
| 몬스터 등급 스탯 배율 | 하급 0.8, 중급 1.0, 상급 1.3, 최상급 1.7 | 정본에 수치 없음 |
| 리프트 등급별 몬스터 레벨 | 균열 1~10, 관문 8~20, 항로 18~35 (`rift-tiers.json`) | 명세 7절 [미정] → 임시값 |
