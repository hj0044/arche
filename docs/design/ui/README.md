# UI 1차 시안 (확정본)

사용자가 확정한 화면 시안(2026-11-23)이다. 정적 HTML이므로 브라우저로 `index.html`을 열면 12화면이 390×844로 나란히 보인다. 각 파일은 한 화면이고 하단 탭과 버튼이 서로 연결돼 있다. **UI 구현(지시서 017)은 이 시안을 기준으로 한다.** 시안과 코드가 다르면 시안이 맞다(AGENTS.md의 "문서가 맞다"와 같은 규칙).

| 파일 | 화면 | 상태 |
|---|---|---|
| Main | 홈(오늘 할 일 허브) | 확정 |
| Content | 콘텐츠 목록(리프트 탭) | 확정 |
| Party | 파티 편성 | 확정 |

| Tower, Boss, Recruit | 탑, 보스, 영입 의뢰 | **[제안]** (설계서에 없는 콘텐츠. 구현 전 지시서에서 범위를 따로 정한다) |

## 구현 준수 규칙 (017에서 절대 지킨다)
1. **구조와 배치**: 화면 구성, 정보의 순서, 카드 레이아웃, 4열 그리드(계약자), 5슬롯(파티 열당 최대 5)을 시안대로 만든다. 순서를 바꾸거나 정보를 빼려면 멈추고 보고한다.
2. **디자인 값**: 아래 값을 `src/ui/theme`(또는 CSS 변수)로 한 곳에 두고 쓴다. 색을 화면 코드에 직접 쓰지 않는다.
3. **터치와 글자**: 터치 영역은 최소 44px. 글자는 최소 11px(보조 표기), 본문 13~16px. 시안보다 작게 만들지 않는다.
4. **그림 자리**: 시안의 초상화, 리프트 배너, 엠블럼, 보스 그림은 임시 SVG다. 구현은 이미지 슬롯(경로 규칙, 비율, 없을 때 대체 그림)으로 만들어 이미지 파일만 넣으면 바뀌게 한다. 임시 SVG는 대체 그림으로 재사용해도 된다.
5. **확인 방법**: 화면마다 390×844 스크린샷을 찍어 시안과 나란히 PR에 싣는다. 눈에 띄게 다른 곳은 이유를 적는다. 가능하면 Playwright 같은 도구로 자동 캡처한다.
6. **어긋남 보고**: 시안대로 만들 수 없는 곳(기술 제약 등)은 임의로 바꾸지 말고 멈춰서 어떤 부분이 충돌하는지 보고한다(CLAUDE.md 규칙).
7. **시안 갱신**: 시안을 바꿀 때는 사용자가 정한다. 구현자가 바꾸지 않는다.

## 디자인 값 (시안에서 쓴 값)
- 색: 배경 `#0E1118`, 패널 `#161B27`, 패널2 `#1E2535`, 선 `#2E3750`, 강조(금) `#E8B04A`, 글자 `#ECEFF6`, 보조 글자 `#A9B2C7`.
- 위험도 5구간: 압도 `#3FCF8E`, 우세 `#9ED65A`, 접전 `#E6CF4A`, 열세 `#F29B5B`, 무모 `#F0706F`. 라벨 옆 5칸 막대(단계 1~5).
- 속성: 화염 `#E8643C`, 냉기 `#5EB6F0`, 대지 `#C79A55`, 공허 `#9B7BE8`(1단계 시안 기준, 나머지 속성은 데이터로 추가).
- 성장 한계 구간 테두리: ~40 `#3A4560`, 45 `#5CC9A0`, 50 `#6FA8FF`(약한 빛), 55~60 `#B58AF0`(빛+보석), 65 이상 `#E8B04A`(강한 빛+보석). 구간 경계는 데이터.
- 특성 종류 색: 공통 `#8FA3C8`, 역할 `#6FA8FF`, 배경 `#5CC9A0`, 고유 `#E8B04A`, 속성 `#E8643C`, 종족 `#B58AF0`.
- 모서리: 카드 14px, 작은 칩과 버튼 10~12px. 간격 8/12/16/20. 화면 좌우 여백 16~20px.
- 하단 탭 64px(홈·콘텐츠·계약자·거점), 상단 로고줄 44px(로고=홈 버튼, 우측 톱니=설정).
- 글꼴 Noto Sans KR 400/500/700. 제목 20px, 카드 제목 15~16px, 보조 12~13px, 큰 숫자 26~30px.
- 아이콘은 인라인 SVG(이모지 사용 안 함).

## 내비게이션 규칙 [제안]
- 하단 4개 탭 사이는 좌우 스와이프로 이동한다(홈 ↔ 콘텐츠 ↔ 계약자 ↔ 거점). 가로로 스크롤되는 칩 줄·슬롯 위에서 시작한 스와이프, 화면 가장자리 20px 안에서 시작한 스와이프는 무시한다. 파티 편성·설정·전투처럼 뒤로 가기로 들어가는 화면에는 스와이프를 넣지 않는다.
- 콘텐츠 화면 안의 서브 탭(리프트/탑/보스/영입)은 탭으로만 이동한다.

## 표기
- 화면 용어: 용병 → **계약자**(`terms.json`), 역할은 수호자·투사·저격수·마도사·사제·전술가·자객·기만자. 시안은 이 이름을 쓴다.
- 이름·수치·레벨은 시안의 예시이고 실제 데이터가 아니다.
