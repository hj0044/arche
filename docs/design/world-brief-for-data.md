# 데이터 작성자용 세계관 요약 (GPT/Codex 등)

이 문서는 이름, 팀, 인물 같은 **데이터를 만드는 작성자**가 세계관을 어기지 않도록 정리한 자체 완결형 요약이다. 정본은 설계서와 설정집(AGENTS.md 링크)이고, 이 요약이 정본과 다르면 정본이 맞다. 상태 태그: [확정]은 지켜야 하는 규칙, [제안]은 초안이다. 확정 사항은 이 문서의 데이터 작업에서 바꾸지 않는다. 애매한 곳은 임의로 정하지 말고 PR 본문과 `docs/open-questions.md`에 질문으로 적는다.

## 1. 세계

- [확정] 배경은 2032년의 현대 도시다. 2027년 "제로데이"에 지구와 여러 이세계를 잇는 통로(리프트)가 열렸고, 일상은 돌아왔지만 도시마다 리프트 방어선과 개방자 등록소가 있다.
- [확정] 에너지는 "아르케", 화폐는 "제로", 균열은 "리프트", 능력자는 "개방자"라고 부른다. 게임 화면에서 용병은 "계약자"라고 표시하고, 용병 조직은 "용병단"이라고 부른다.
- [확정] 리프트는 균열(몬스터만 넘어옴), 관문(인물도 넘어옴), 항로(세계 단위로 연결되어 영구히 안정화할 수 있음) 3등급이다.
- [확정] 지구연합이 개방자 등록제를 운영한다. 이세계인은 허가제로 지구에 체류한다.
- [확정] 이세계는 여러 곳이고 이름이 정해져 있다: 판타지계 아르카디아, 무림계 중원, 마계 이그리스, AI 디스토피아계 시냅스. 이번 데이터 작업에는 이세계 인물을 넣지 않는다(전부 지구 출신).
- [확정] 흑막(이름 "아르케의 포식자")은 징조 → 간부급 → 본체 순으로 단계적으로 드러난다. **이번 데이터 작업에서는 흑막, 공허 속성 몬스터, 징조를 직접 언급하지 않는다.**
- [확정] 계약자는 영구적으로 죽지 않는다. 쓰러지면 부상 상태가 된다. 설정에 "전사했다", "죽었다"를 쓰지 않는다(과거 이야기로도 쓰지 않는다. 대신 "실종", "은퇴", "해산" 같은 표현을 쓴다).

## 2. 분류

- 역할 8종(id: 표시명): shield 수호자, warrior 투사, archer 저격수, mage 마도사, healer 사제, commander 전술가, assassin 자객, disruptor 기만자.
- 속성 7종(id: 화면 표기명): fire 화염, wind 바람, earth 대지, lightning 전격, frost 냉기, light 빛, void 어둠. 화면 표기명만 쓰고, 설정명(연소, 확산, 지맥, 방전, 응결, 봉합, 공허)은 쓰지 않는다.
- 계약자 배경 10종(id: 표시명): survivor 제로데이 생존자, agent 전직 공공기관 요원, corporate 메가코프 출신, citizen 평범한 시민, soldier 전직 연합군 군인, researcher 리프트 연구자, wanderer 떠돌이 용병, heir 길드 계승자, mercenary_company 용병단 출신, freelancer 민간 프리랜서.
- 도시 9곳(id: 이름): seoul 서울, tokyo 도쿄, newyork 뉴욕, london 런던, lagos 라고스, saopaulo 상파울루, mumbai 뭄바이, dubai 두바이, sydney 시드니. 허구 도시는 만들지 않는다. 도시 색(임시, [제안]): 서울은 24시간 돌아가는 고밀도 도시, 도쿄는 질서와 정밀함, 뉴욕은 다민족·자본·계약 사회, 런던은 오랜 가문과 기사 전통, 라고스는 젊고 거친 균열 밀집 지역, 상파울루는 초대형 도시와 자경단·길드 문화, 뭄바이는 인구 밀집과 대중문화, 두바이는 계획 신도시와 두터운 방어선, 시드니는 고립된 항구 도시.
- 균열이 몰리는 도시가 있고 개방자가 많이 나오지만, 그 이유는 아무도 모른다(원인 불명) [확정]. 이유를 설명하는 문장을 쓰지 않는다.

## 3. 세력 (세계관 전용)

세력은 게임 수치에 영향이 없고 소속, 분위기, 소개 문구에만 쓴다. 팀의 소속 세력 id는 아래 6개 중 하나다.

| id | 이름 | 성격 |
|---|---|---|
| rrb | 리프트 대응국 | 공공기관 용병. 규율과 안정 |
| archon | 아르콘 에너지 | 메가코프(에너지). 아르케 정제와 시설 |
| bulwark | 불워크 시스템즈 | 메가코프(군수·기술). 중장갑·드론, "방벽"이라는 뜻 |
| waypoint | 웨이포인트 컴퍼니 | 민간 용병단. 민간 파견 중개 업체 |
| indie | 독립 강자 모임 | 초강력 개방자 소수 정예 용병단과 독립 강자들. 명예와 독립성 |
| free | 무소속 | 조직 이름 없이 라벨만 쓴다 |

- 이 외 세력은 쓰지 않는다. 도깨비불 세력은 삭제됐으니 쓰지 않는다.
- 메가코프 업종은 에너지, 군수·기술, 의료·생명, 정보·AI 4개가 있는데, 의료·생명과 정보·AI는 아직 세력 id가 없다. 그 업종의 팀은 소속 세력을 `free`로 두고 소개 문구에 업종만 적는다.

## 4. 용병단 리그 설정 (일부 [제안])

- [확정] 지구연합이 용병단 공인 등급 인가제를 운영한다. 용병단은 등급(미진, 약진, 중진, 강진, 격진 순으로 높아짐)에 따라 들어갈 수 있는 리프트가 다르고 시즌마다 승강한다. 팀 규모(인원)와 등급은 서로 독립이다.
- [확정] 규모 단계: 1단계 4~5명, 2단계 5~10명, 3단계 10~20명, 4단계 20~40명, 5단계 40명 초과.
- [확정] 소수 용병단은 6곳만 남는다: 애셔 오스(영어 "재의 서약", 오래된 맹세에 묶인 베테랑 팀), 오보로(일본어 "흐릿한 달빛", 은신과 암습), 코르보 네로(이탈리아어 "검은 까마귀", 정보와 용병 중개), 람 부알레(프랑스어 "베일에 싸인 칼날", 신원 불명의 암살단), 인고냐마(줄루어 "사자", 명예를 건 정면 돌격), 바즈라(산스크리트어 "금강, 번개", 수련과 의식을 중시하는 집단). 이들은 소규모 정예이며 독립 강자 모임에 속한다.

## 5. 문체와 금지

- [제안] 톤은 현실감 있는 현대 판타지다. 지나치게 만화적이거나 지나치게 어둡지 않게 쓴다. 이름과 소개 문구는 한국어로, 짧고 선명하게.
- 현실의 실존 인물, 실존 단체, 저작권이 있는 작품의 고유 인물·고유 명칭을 쓰지 않는다.
- 노년 느낌의 촌스러운 이름은 쓰지 않는다. 현대에 실제로 쓰이는 개성 있는 이름을 쓰고, 귀족적이고 고전적인 격조는 일부 허용한다.
- 국적이나 문화권으로 역할·성격·직업을 정하지 않는다(고정관념 금지). 같은 문화권 안에서도 다양하게 쓴다.
- 비속어나 욕설과 같은 소리로 읽히는 이름, 특정 집단을 비하하는 이름, 역사적 학살자·독재자·테러범과 강하게 연결된 이름은 쓰지 않는다. 신의 이름처럼 신성하게 여겨지는 이름을 단독으로 쓰지 않는다.
- 이름은 모두 한글로 쓴다(영문 표기 금지). 외국어는 해당 언어의 원음에 가깝게 외래어 표기법에 따라 적는다.
