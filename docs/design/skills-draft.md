> 상태: [제안] 초안(2026-11-24 사용자 확정 방향 반영). 모든 수치는 임시값이고 데이터 표로 분리한다. 구조: 기본 공격 1개 + 액티브 3개(역할 풀 6개에서 배정) + 패시브는 특성.

## 상태 효과 5종 (전투 안에서만 유지)

| 이름 | 효과 | 기본 지속 |
|---|---|---|
| 기절 | 행동하지 못한다. 풀린 다음 라운드에는 다시 걸리지 않는다. | 1라운드 |
| 지속 피해 | 자기 차례가 시작될 때 피해를 입는다. 방어는 적용되고 변동은 없다. | 3라운드 |
| 보호막 | 체력보다 먼저 피해를 흡수한다. 시간이 끝나면 남은 양은 사라진다. | 3라운드 |
| 표식 | 받는 피해가 25% 늘어난다. | 2라운드 |
| 약화 | 주는 피해와 치유량이 25% 줄어든다. | 2라운드 |

공통 규칙(제안): 같은 효과를 다시 받으면 지속 시간만 갱신하고 겹치지 않는다. 기절이 풀린 다음 라운드에는 기절에 걸리지 않는다(연속 기절 방지). 지속 시간은 효과를 받은 유닛의 라운드가 끝날 때 1씩 줄어든다. 효과는 항상 적중하고 확률은 쓰지 않는다. 전투가 끝나면 모두 사라진다.
