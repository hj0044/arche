# 경제·성장 수치 점검 (2026-11-20)

`npm run economy-sweep -- 60 10`(60일, 시드 10개)과 `npm run balance`, `npm run days`로 잰 결과다. 자동 플레이 정책은 `loyalty-sweep`과 같고(파티 1개, 제로가 영입비+300이면 영입, 급료 보너스 안 씀), 사람 플레이보다 미납이 많이 나온다.

## 바꾼 값 (1개)
| 값 | 이전 | 이후 | 근거 |
|---|---|---|---|
| `progression.upkeepZeroPerDay.base` | 5 | 3 | 미납 이벤트 137 → 84(−39%). 승리 232 → 236, 길드 인원 5.5 → 6.9. 충성도 이탈의 가장 큰 원인이 미납이었다. 거점 시설(008)이 제로를 쓰기 전에 여유를 둔다. |

## 바꾸지 않은 값과 이유
- 경험치(승리 30 → 40, 45 등): 상위 5명 평균 레벨이 9.5 → 9.8~10.1로 노이즈 수준. 자동 플레이는 영입 인원이 늘어 경험치가 나뉘기 때문이다. 경험치 배율은 사람 플레이 후에 정한다.
- 레벨업 아르케 비용, 아르케 보상: 바꿔도 결과가 100% 같다. 아르케는 병목이 아니다.
- 충성도·무소속 이동 값: 007 비교표 결론 그대로(기본값 유지).
- 리프트 보상 제로 ×1.3: 승리는 그대로이고 패배만 늘었다(경제가 아니라 난이도가 병목).

## 발견 (사용자 확인 필요)
1. **승률은 절벽형**이다. 시작 4인 파티 기준 필요 레벨은 대략 균열 중급 Lv20 → Lv13~15, 관문 중급 Lv15 → Lv9~10, 관문 중급 Lv25 → Lv18~20, 관문 상급 Lv30 → Lv26. 파티 레벨이 몬스터 −5 근처에서 0%에서 100%로 넘어간다.
2. 자동 플레이 60일에 상위 5명 평균이 Lv9~10이라 관문은 60일쯤에 열리고, 항로(Lv30+)는 지금 속도로는 한참 뒤다. 파견을 여러 개 돌리는 사람 플레이는 더 빠를 수 있어 플레이 후 판단한다.
3. **`npm run balance` 표 주의**: "같은 레벨"과 "레벨 차이" 표는 방패·전사·사수·술사·치유사 균형 5인 파티 기준이라 낙관적이다(Lv5 vs 중급 Lv15×3이 100%). 시작 4인 파티는 같은 조건에서 Lv5 0%, Lv8 45%다. 표 해석 시 파티 구성에 따라 크게 달라진다는 점을 감안한다.
