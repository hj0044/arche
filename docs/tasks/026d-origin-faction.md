# 026d — 세력은 "출신 세력"(연고)으로 (Claude Code)

사용자 확정(2026-11-26): 용병/계약자에게 붙는 세력은 "현재 소속"이 아니라 **출신 세력(연고)** 이다. 영입해도, 이탈해도 그대로 남는다. 세력은 계속 세계관 전용이며 게임 수치에 개입하지 않는다(나중에 시너지에 쓸 수 있게 자리만 연다). 용어: NPC는 NPC, 영입 가능한 인물은 용병/계약자(AGENTS.md).

## 1. 개념 분리

- **출신 세력**(`originFaction`): 세력 id 또는 `null`(연고 없음). 계약자 프로필의 고정 값이다. 영입, 이탈, 길드 이동으로 바뀌지 않는다.
- **현재 소속**(`affiliation`): 우리 길드(`guild`) 또는 무소속(`unaffiliated`)이다. 계약자는 더 이상 `kind: 'faction'` 소속을 갖지 않는다. 길드에 있지 않은 계약자는 모두 무소속이다(영입 후보든 이탈자든). 영입 가능 여부는 "길드가 아님"으로 판단한다. 몬스터 소속(`monster`)은 그대로다.
- `roster.json`의 `faction` 필드를 `originFaction`으로 이름을 바꾼다. 값은 세력 id 또는 `null`이다. 지금 `"guild"`로 되어 있는 시작 길드 계약자 4명은 배경에 어울리는 출신 세력(또는 `null`)을 정하고, "시작부터 길드" 여부는 이미 있는 시작 후보 표시 필드를 쓰거나 새 필드로 둔다(구현자가 정하고 PR에 적는다).
- 충성도 이탈: 현재 소속만 `unaffiliated`로 바뀐다. 출신 세력은 그대로다. `loyalty.json`의 `simulatedAffiliations`는 `guild`만 유지한다.
- 데이터 무결성: `originFaction`은 세력 표에 있는 id이거나 `null`이다.

## 2. 화면 (문구와 필터만 바꾼다, 구성은 그대로)

- 라벨 "소속"을 "출신 세력"으로 바꾼다(영입 화면 목록·상세 시트·필터 시트, 계약자 상세의 식별 줄). 연고가 없으면 "연고 없음"으로 표시한다.
- 계약자 상세 식별 줄: `도시 · 출신 세력 · 배경`(길드원이어도 길드 이름 대신 출신 세력을 보여 준다. 길드원인지는 목록 위치가 이미 알려 준다).
- 영입 필터: "소속" 필터를 "출신 세력"으로 이름을 바꾼다. 세력 칩은 지금처럼 그 세력 출신 계약자가 한 명이라도 있는 세력만, "무소속" 칩은 "연고 없음" 칩으로 바꾸고 항상 둔다. 계약자 목록 필터의 세력 조건도 같은 규칙을 쓴다.
- `docs/design/ui/`의 시안(Recruit, RecruitSheet, MercDetail, Merc 등)과 `contract.json`의 해당 문구도 같은 값으로 맞추고 사진을 갱신한다. 이번에 한해 시안 문구 수정은 사용자가 승인했다(구성은 바꾸지 않는다).

## 3. 세이브

- 세이브 버전을 현재에서 하나 올린다(027b와 순서에 상관없이 각자 한 번 올린다). AGENTS.md 규칙에 따라 마이그레이션 없이 이전 버전은 거절한다. 무결성 검사: `originFaction`이 세력 id이거나 null, 계약자 소속 kind는 `guild`/`unaffiliated`만, 이전 `faction` kind가 남은 세이브 거절.

## 4. 검증

- 영입 후에도, 이탈 후에도 출신 세력이 그대로다. 영입비·충성도·점수는 출신 세력과 무관하다(기존 테스트 유지). `balance 400`과 전투 결과가 그대로다.
- 영입 후보 목록이 이전과 같은 사람들이다(영입 가능 판단이 "길드가 아님"으로 바뀌어도 후보가 달라지지 않는다. 시작 길드 4명은 후보가 아니다).
- 필터: 출신 세력 칩, "연고 없음" 칩, 소속 계약자가 없는 세력 칩 숨김. `npm test`, `typecheck`, `build`, `ui:check` 통과.
- `docs/design/phase1-spec.md`, `docs/open-questions.md`에 세이브 버전과 "출신 세력" 의미를 기록한다.

## 5. 하지 않는 것

출신 세력을 쓰는 시너지·수치 효과(나중에 설계서에서 정하고 지시서를 따로 낸다), NPC 팀의 세력 필드 변경(팀은 세력 소속이 맞다), 새 세력 추가, 계약자 이름·스탯 조정.
