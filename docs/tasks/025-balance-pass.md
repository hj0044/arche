# 지시서 025: 1단계 밸런스 패스 (기만자·기절 보강, 접전 목표 완화 반영)

사용자 위임(2026-11-25): "밸런스는 알아서". 이 지시서는 목표와 허용 범위를 정하고, 값은 구현자가 측정해서 정한다. 규칙·구조는 바꾸지 않는다. 설계서는 접전·우세 80% 목표를 참고 지표로 완화했다(변경 기록 있음). 이 목표를 맞추려고 값을 조정하지 않는다.

## 1. 목표 (측정으로 확인)
1. **기만자 보강**: 역할별 "파티 기여도"(같은 기준 파티에서 한 자리를 그 역할로 바꿨을 때의 승률 변화)를 재서, 기만자가 8개 역할 평균의 80% 이상이 되게 한다. 수호자·사제·전술가는 1대1에서 약한 것이 정상이므로 1대1이 아니라 파티 기여도로 본다. 측정 스크립트가 없으면 `scripts/role-balance.ts`와 `npm run role-balance`를 만든다(`status-impact.ts`를 참고, 시드 800 이상).
2. **기절 존재감**: 기절이 있는 파티와 같은 파티에서 기절 스킬을 다른 스킬로 바꾼 파티의 승률 차이가 3%p 이상이 되게 한다(지금은 작음). 연속 기절 금지 규칙은 유지한다.
3. **표식**: 표식을 쓰는 기만자 파티가 표식을 안 쓸 때보다 불리하지 않게 한다(순효과 0 이상).
4. **보존 기준**: 016의 승률·위험도 보존 기준(±5%p)과 위험도 일치 보호선을 깨지 않는다. 깨는 조정은 하지 않고 보고한다.
5. 참고 지표(조정하지 않음): 접전·우세 있는 날 비율, 가용 인원별 비율을 지금과 같은 방법으로 재서 표로 남긴다.

## 2. 허용 범위
- 바꿀 수 있는 것: `skills.json` 기만자·관련 스킬 수치(위력, 쿨다운, 상태 효과 확률·지속 라운드, 대상), `statusEffects.json`의 수치, `roles.json` 기만자 기본값과 역할 특성 수치, 기만자 계약자 3명의 baseStats·growthRates(예산 95~105% 규칙 유지).
- 바꾸지 않는 것: 상태 효과 5종 종류와 규칙, 스킬 구조(기본 1 + 액티브 3), 타깃팅·후열 규칙, 위험도 경계값, 15라운드 규칙, 다른 역할의 수치(기만자 조정 때문에 다른 역할이 깨지면 보고).
- 한 번에 바꾸는 값은 적게 하고(한 스킬 또는 한 수치), 바꿀 때마다 측정해서 표로 남긴다. 조정 횟수는 8회까지.

## 3. 출력
