# 027 — 활약도 기록 (Claude Code)

설계서 "리그와 세계 확장 > 랭킹과 보상"의 [확정] "활약도는 전투 기여를 역할 평균 대비로 정규화해서 센다. 시즌 누적과 통산, 두 가지로 기록한다"를 구현한다. 이번 지시서는 **기록과 표시까지**다. 순위·보상은 028(리그)에서 한다. 화면은 `docs/design/ui/Records.html`(확정)을 따른다.

## 1. 기여 항목 8개

전투 이벤트에서 계약자(아군 길드원)별로 센다. 적과 NPC는 기록하지 않는다. 항목은 데이터 행이라 나중에 늘릴 수 있다.

| id | 표기 | 세는 방법 |
|---|---|---|
| damage | 입힌 피해 | 내가 입힌 피해 합계(지속 피해 틱 포함, 보호막이 흡수한 양 포함) |
| kill | 처치 | 마지막 일격으로 적을 쓰러뜨린 횟수 |
| guard | 막은 피해 | 내가 건 보호막이 흡수한 양 + 도발 중인 내가 받은 피해 |
| heal | 회복 | 실제로 늘어난 체력 합계(넘친 양 제외) |
| status | 상태이상 부여 | 적에게 건 기절·지속 피해·표식의 횟수(면역으로 막힌 것은 제외) |
| cleanse | 상태이상 해제 | 아군에게서 해제한 상태 개수 |
| buff | 아군 강화 | 아군에게 건 강화 횟수(대상 수만큼) |
| debuff | 적 약화 | 적에게 건 약화(능력치 저하) 횟수 |

- 지속 피해·약화·표식·보호막처럼 "건 사람"과 "효과가 발동하는 때"가 다른 것은 상태에 `sourceKey`(건 유닛)를 기록해 귀속한다. 이 변경은 전투 결과를 바꾸면 안 된다(같은 시드 → 같은 로그, 난수 사용 순서 불변).
- 이벤트에 필요한 필드만 더한다. 기존 필드 의미는 바꾸지 않는다.

## 2. 활약도 계산

- 활약도 = 100 × Σ(가중치[역할][항목] × 내 값 ÷ 기준값[역할][항목]) ÷ Σ 가중치[역할]. 같은 역할 평균이 100이다.
- 가중치가 0인 항목은 그 역할에서 계산에서 빼고, 화면에는 "이 역할은 해당 없음"으로 흐리게 표시한다(점수에 불이익 없음).
- 항목마다 가중치가 다르다. 피해와 처치도 같지 않다: 처치는 피해보다 낮게 둬서(예: 피해 1.0, 처치 0.6) 마무리만 노리는 쪽이 유리하지 않게 한다. 역할별 가중치 예(전부 임시값): 방패는 막은 피해·도발 비중 큼, 힐러는 회복·해제·강화 큼, 마법사·궁수는 피해·처치 큼, 교란자는 상태이상 부여·약화 큼, 지휘관은 강화·약화 큼, 암살자는 처치·피해 큼, 전사는 피해·막은 피해 균형.
- 기준값[역할][항목]은 임시값이고 `npm run sim`·`balance` 표본으로 역할별 평균을 뽑아 채운다(같은 시드 표본이면 같은 값). 기준값이 0인 항목은 가중치 0과 같다.
- 한 번의 공략(전투 묶음) 활약도와 시즌·통산 누적 활약도를 모두 계산한다. 누적은 항목 합계로 다시 계산한다(공략별 점수의 평균이 아니다).
- 데이터: `src/data/contribution.json`(항목 행, 역할별 가중치, 역할별 기준값, 시즌 길이 30일). 코드에 수치를 박지 않는다.

## 3. 기록 저장

- 계약자마다 시즌과 통산 두 벌의 항목 합계, 출전·클리어·쓰러짐 횟수, 최근 공략 기록(최대 10건: 일차, 리프트 이름·등급, 활약도, 결과)을 가진다. 계약자가 길드를 떠나도 기록은 남긴다.
- 시즌 번호는 `floor((일차 − 1) ÷ 시즌 길이) + 1`이다. 리그 시즌(028)이 생기면 그쪽 번호로 바꾸기 쉽게 한 곳에 둔다. 시즌이 바뀌면 시즌 합계는 새로 시작하고 통산은 유지한다. 지난 시즌 합계는 계약자별로 최근 5시즌까지만 남긴다.
- 세이브 버전을 13으로 올린다. AGENTS.md 세이브 규칙에 따라 마이그레이션은 만들지 않고 v12 이하는 "지원하지 않는 세이브"로 거절한다. 기록 합계가 항목 합과 어긋나지 않는지 무결성 검사를 더한다.
- 쓰러짐은 영구 사망이 아니다. 표기는 "쓰러짐(부상)"이다. "죽음·전사·사망"은 화면과 데이터 어디에도 쓰지 않는다.

## 4. 화면

- `docs/design/ui/Records.html` 그대로 만든다: 이번 시즌/통산 토글, 활약도 큰 숫자와 역할 평균 100 표시선, 전사 순위 자리(점선 박스, "리그 시작 후 표시 (028)"), 항목별 기여 8칸(2열), 출전·클리어·쓰러짐, 최근 공략 목록. 항목이 늘어 한 화면을 넘으면 본문만 스크롤하고 헤더와 하단 버튼은 고정한다.
- 계약자 상세 화면 하단에 "기록" 버튼을 더해 이 화면으로 들어간다. 상세 화면의 기존 구성·순서는 바꾸지 않는다(필요한 곳은 하단 버튼 영역뿐).
- `docs/design/ui/contract.json`에 `records` 구역(순서와 data-ui id)을 더하고, 390×844 스크린샷을 시안과 나란히 PR에 싣는다. 터치 영역 44px, 글자 11px 이상.
- 기록이 없는 계약자는 값 0과 "아직 공략 기록이 없습니다"를 보여 준다(점수는 "—").

## 5. 검증

- 항목별 세는 방법 테스트: 지속 피해 틱, 보호막 흡수, 도발 중 피해, 넘친 회복 제외, 면역으로 막힌 상태 제외, 건 사람에게 귀속.
- 같은 입력과 시드면 같은 기록(결정성). 기록 추가 전후로 전투 로그와 결과가 같다(`balance 400`이 그대로).
- 활약도 계산 테스트: 역할 평균 값을 넣으면 100, 가중치 0인 항목은 점수에 영향 없음, 피해와 처치 가중치가 다르면 점수가 달라짐.
- 시즌 경계(60일), 통산 유지, 이탈한 계약자 기록 보존, 세이브 v13 거절과 무결성 검사.
- `npm test`, `typecheck`, `build`, `ui:check` 통과.
