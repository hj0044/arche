# 지시서 017c: 영입 카드에 레벨/최대 레벨 표시 (소규모 패치)

사용자 요청(2026-11-24): 영입 화면에서 계약자의 레벨과 최대 레벨(성장 한계)이 안 보여 불편하다. 설계서 [확정]에도 "성장 한계와 최초 레벨은 영입 전부터 프로필에 모두 보여준다"가 있다.

## 1. 구현
- 영입 탭(`src/ui/screens/Content.tsx`의 `RecruitList`) 카드의 초상 왼쪽 위에 `레벨/성장 한계` 배지를 둔다(예: `4/50`). 계약자 목록 카드(`MercList`)의 배지와 같은 컴포넌트·모양을 쓴다(새로 만들지 않는다). 값은 `initialLevel`(길드에 없는 계약자는 최초 레벨)과 `growth.cap`이다. 영입 가능·진행 중 카드에 보이고, 잠김 카드는 이름이 `???`이라 배지도 숨긴다.
- 시안(정본): `docs/design/ui/Recruit.html`, `contract.json`의 `Recruit.cards`. 시안과 다르게 만들지 않는다. `data-ui="recruit.level"`을 붙인다.
- `ui:shots`를 다시 찍어 Recruit compare 이미지를 PR에 붙이고, `ui:check`에 "영입 가능·진행 중 카드마다 배지가 있고 형식이 `숫자/숫자`다, 잠김 카드에는 없다" 검사를 추가한다.

## 2. 하지 않는 것
다른 화면 변경, 정렬·필터 추가, 영입 조건·비용 변경.

## 3. 완료 조건: 머지와 배포까지 (AGENTS.md 확정 규칙, 이 지시서의 일부)
1. 테스트·타입 검사·빌드·`ui:check`가 통과한 PR을 연다.
2. 사용자 확인을 기다리지 않고 바로 `main`에 머지한다.
3. Render 배포가 `live`가 된 것을 확인한다. 실패하면 고쳐 다시 머지한다.
4. 최종 보고는 "배포 완료", 배포 커밋, Recruit compare 이미지로 한다. 020보다 먼저 끝낸다.
