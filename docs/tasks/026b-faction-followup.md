# 026b — 세력 정리 마무리 (Claude Code)

026 검수에서 정한 작은 후속이다. 새 기능은 없고 정리만 한다. 설계서 "리그와 세계 확장" 절의 "세력은 세계관 전용" [확정]을 따른다.

## 1. 충성도 시뮬레이션 대상은 길드만

- `src/data/loyalty.json`의 `_note`에서 "3단계에서 다른 세력을 켠다" 문구를 지우고, `simulatedAffiliations`는 지금 `guild`만 쓴다고 고쳐 쓴다(세력은 세계관 전용이라 충성도 계산 대상이 아니다).
- 데이터 무결성 테스트(`data.test.ts`)에 `simulatedAffiliations`가 `guild`만 담는지 보는 검사를 추가한다.
- 구조(배열과 `isSimulated` 같은 판정 함수)는 지우지 않는다. `loyalty-extension.test.ts`의 `['guild', 'rrb']` 확장 테스트는 "구조는 확장 가능"을 보는 용도라면 그대로 둔다. 데이터 검사와 충돌하지 않는지만 확인한다.

## 2. `departedDay`는 그대로 둔다

바꾸지 않는다. 027(활약도 기록)에서 이탈 이력에 쓸 수 있다.

## 3. 영입 필터의 세력 칩은 소속 계약자가 있는 세력만

- `src/ui/recruitFilter.ts`의 `recruitChips`가 세력 표 전체를 주고 있다. 현재 로스터에서 한 명이라도 그 세력 소속이면 칩으로 보이게 한다. 지금은 `bulwark`가 빠지고 나머지 5개(rrb, archon, indie, waypoint, free)가 보인다.
- "소속 계약자"는 영입 목록에 보이는 로스터 전체를 기준으로 한다(이미 영입한 계약자나 잠긴 계약자 때문에 칩이 사라지거나 생기지 않도록 로스터 데이터 기준).
- 나중에 `bulwark` 소속 계약자가 로스터에 생기면 코드 수정 없이 자동으로 칩에 나온다. 이 동작을 테스트로 고정한다(소속 0명인 세력은 칩에 없음, 1명 이상이면 있음).
- 화면 구성은 바꾸지 않는다. 칩 개수가 바뀌어 사진이 달라지면 `docs/design/ui/` 사진과 `contract.json`을 같은 값으로 맞춘다.

## 4. 하지 않는 것

도시 영향력 값 확장(도시 확장 지시서에서 다룬다), 세력 UI 개편, D01·D02, 027 이후 기능, 세이브 형식 변경(버전은 올리지 않는다).
