# 지시서 011: 패배 후 재편성, 리프트 목록 위험도, 복귀 보고의 성장 연결

Codex 플레이 검수(최신 배포판 14턴, 390×844)에서 나온 UX 보완 세 가지다. 정본은 설계서의 전투력·위험도 항목과 변경 로그 2026-11-20 마지막 행이다. 문서와 코드가 다르면 문서가 맞다. [확정]은 지켜야 하는 규칙, [제안]은 바꿔도 되지만 보고, [미정]은 구현하지 말고 질문한다. 충돌하거나 비어 있는 곳은 임의로 정하지 말고 `docs/open-questions.md`에 적고 보고한다.

## 배경

- 위험도는 맞게 나왔다(시작 용병 조합 120개 조건에서 탐지소 Lv1 표시 범위가 120/120, Lv2가 119/120으로 실제 승률 단계를 포함). 그래서 수치는 건드리지 않고 **보여 주는 위치와 연결**을 고친다.
- 패배로 팀이 부상하면 지금 출전 가능한 인원, 회복일, 그때까지 드는 유지비를 여러 화면에서 직접 맞춰 봐야 한다.
- 위험도는 편성 화면까지 들어가야 보여서 리프트를 비교할 때 쓰기 어렵다.
- 복귀 후 레벨업 가능 여부를 용병 목록에 따로 가서 확인해야 한다.

## 하지 않는 것 (유지)
- [확정] 파견 확인 창은 만들지 않는다. "무리" 경고를 보고도 출전하는 것은 플레이어 선택이다.
- 수치 조정(위험도 경계, 경험치, 유지비 등)은 하지 않는다. 밸런스는 사용자의 플레이 이후에 정한다.
- 인원을 한 명 뺐을 때의 나란히 비교 표시는 만들지 않는다(보류, 설계서 미결에 둠).

## 작업 목록

### 1. 패배 후 재편성: "지금 상황" 요약
- 하루 결과(`DayResult`)와 길드 홈에 다음을 묶어 보여준다.
  - 지금 출전 가능한 인원 수(부상, 파견 중, 거부, 훈련 배치 제외)
  - 가장 빠른 복귀일과 가장 빠른 회복일
  - 그날까지 드는 유지비 합계(복귀·회복일까지의 일수 × 하루 유지비. 길드 소속 용병 기준)
- 출전 가능 인원이 부족하면(예: 파티 최소 인원보다 적음) 이유별로 인원을 나눠 보여준다(부상 N명, 파견 중 N명, 훈련 N명).
- 훈련 배치된 용병이 있으면 편성 화면에서 훈련 배치 해제 화면(시설)으로 바로 이동하는 연결을 둔다. 훈련 중인 용병은 파견에 쓸 수 없다는 기존 규칙은 그대로다.
- 계산은 엔진의 순수 함수(예: `guildStatusSummary`)로 만들고 화면은 그것만 쓴다. 같은 입력이면 같은 결과다.

### 2. 리프트 목록의 위험도와 편성 화면 정보 우선순위
- 리프트 목록 카드마다 "지금 가용 인원으로 자동 편성했을 때의 위험도"를 보여준다. 자동 편성(`autoParty`)과 위험도 계산(`estimateRisk`)을 그대로 쓰고, 탐지소가 보여 주는 정보(`visibleRift`)만으로 계산한다(숨은 값 금지).
- 가용 인원이 없으면 위험도 대신 "출전 가능 인원 없음"을 보여준다. 위험도에 "추정" 표시와 구간 표시 규칙은 010과 같다.
- 리프트가 여러 개일 때 계산이 느려지지 않게 메모이제이션한다(같은 파티·리프트·탐지소 레벨이면 같은 결과). 리프트 목록이 끊기면 계산 시점을 늦추거나 시뮬레이션 횟수를 줄이고 어떻게 했는지 보고한다.
- 편성 화면 첫 화면(스크롤 없이 보이는 영역)에는 위험도, 복귀일, 인당 경험치를 우선 놓는다. 전투력 세부와 도움말은 접어 두고 눌러서 펼친다. 390×844에서 후보 목록의 마지막 용병까지 스크롤로 닿는지, 후보 한 명이 일부만 보이는 구간이 없는지 확인한다.

### 3. 복귀 보고에서 성장으로 연결
- 복귀 보고(`DayResult`)에 "이번에 레벨업 가능해진 용병"을 표시한다. 레벨업이 가능한 용병마다 필요한 아르케를 함께 보여주고, 누르면 용병 상세로 이동한다.
- 경험치는 찼는데 아르케가 모자라 못 올리는 용병은 "필요 아르케 N, 부족 M"으로 따로 표시한다(레벨업 가능 여부를 못 봐서인지 아르케 부족인지 구분이 안 되는 문제 대비).
- 파견 중인 용병은 레벨업할 수 없는 기존 규칙을 따른다(표시도 하지 않는다). 부상 중인 용병은 레벨업할 수 있다.

### 4. 테스트
- 지금 상황 요약: 부상, 파견 중, 훈련 배치, 거부 용병이 섞인 상태에서 인원과 일수, 유지비가 맞는다. 같은 입력이면 같은 결과다.
- 리프트 목록 위험도: 숨은 값만 다르고 보이는 정보가 같은 두 리프트는 같은 표시가 나온다. 가용 인원이 없으면 위험도를 보여주지 않는다.
- 위험도 계산이 세이브 상태와 실제 전투 결과를 바꾸지 않는다(010 규칙 유지).
- 레벨업 가능 표시: 경험치 충족과 아르케 충족, 아르케 부족, 파견 중 제외가 각각 맞는다.
- 390×844 브라우저에서 위 세 화면을 직접 확인하고 결과를 보고한다.
