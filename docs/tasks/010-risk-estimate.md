# 지시서 010: 전투력과 예상 위험도

편성 화면에서 "이 파티로 이 리프트를 이길 수 있는지" 감을 잡게 한다. 정본은 설계서 "파견과 전투"의 전투력·위험도 항목과 변경 로그 2026-11-20 마지막 행이다. 문서와 코드가 다르면 문서가 맞다. [확정]은 지켜야 하는 규칙, [제안]은 바꿔도 되지만 보고, [미정]은 구현하지 말고 질문한다. 충돌하거나 비어 있는 곳은 임의로 정하지 말고 `docs/open-questions.md`에 적고 보고한다.

## 배경

승패가 절벽처럼 갈린다(파티 레벨이 몬스터보다 약 5 낮은 근처에서 0%에서 100%로 넘어감). 속성 상성과 역할 조합도 크게 작용해서, 레벨 숫자만으로는 이길 수 있는지 판단할 수 없다.

## 규칙

- [확정] 편성 화면에 내 파티의 전투력과 선택한 리프트의 예상 위험도를 보여준다.
- [제안] 전투력: 파티원 스탯 합산 숫자. 스탯별 가중치는 데이터 표로 둔다. 리프트 쪽도 같은 식으로 환산해 "상대 추정"으로 나란히 보여준다.
- [제안] 위험도 4단계: 안전, 해볼 만, 위험, 무리. 구간 경계(승률 기준)와 시뮬레이션 횟수는 데이터 표로 둔다. 임시값은 안전 ≥ 90%, 해볼 만 60~89%, 위험 25~59%, 무리 < 25%, 시뮬레이션 12회.
- [제안] 위험도는 전투 엔진을 고정 시드로 여러 번 돌린 승률 구간으로 정한다. 시드는 리프트 id와 회차로 만든다(`power:리프트id:회차`). 실제 전투 시드는 절대 쓰지 않는다(실제 결과가 새어 나간다).
- [확정] 위험도는 탐지소가 보여 주는 정보(`visibleRift`)만으로 계산한다. 숨은 값(정확한 레벨, 마릿수 등)을 쓰면 안 된다.
- [제안] 보이는 정보가 범위(레벨 범위, 마릿수 범위)면 범위의 양 끝 조합을 각각 계산하고, 결과가 서로 다른 단계면 "해볼 만 ~ 위험"처럼 구간으로 보여준다. 같은 단계면 한 단계만 보여준다.
- 정확한 승률 퍼센트는 보여주지 않는다(가짜 정밀도 방지). 실제 전투에는 변수가 있어 보장이 아니라는 안내 문구를 짧게 둔다.

## 작업 목록

### 1. 데이터
- `combat-power.json`(이름은 구현자가 정해도 됨): 전투력 스탯 가중치, 위험도 단계 이름과 승률 경계, 시뮬레이션 횟수. 코드에 숫자를 박지 않는다.
- 단계 수와 경계를 바꾸면(예: 5단계) 화면과 계산이 따라와야 한다.

### 2. 엔진 (`src/engine/`, 화면 의존 금지)
- `combatPower(tables, 파티)`: 전투력 숫자. 파티원의 실제 현재 스탯(충성도 보정 포함)을 쓴다.
- `estimateRisk(tables, 파티, VisibleRift)`: 위험도. 인자로 `Rift`가 아니라 `VisibleRift`만 받게 해서 숨은 값을 쓸 수 없게 한다.
- 순수 함수이고 같은 입력이면 같은 결과다. 편성이 바뀌면 다시 계산하고, 같은 입력은 메모이제이션한다.
- 위험도 계산 때문에 세이브 상태나 실제 시드(난수 흐름)가 바뀌면 안 된다.

### 3. 화면 (390×844 기준)
- 편성 요약에 전투력(내 파티 / 상대 추정)과 위험도 표시를 추가한다. 인원이나 편성을 바꾸면 즉시 갱신된다.
- 색에만 의존하지 말고 글자로 단계 이름을 쓴다. 터치 영역과 글자 크기 기준은 기존과 같다.
- 탐지소 레벨이 낮아 구간으로 나오면 "추정" 표시를 붙인다.
- 계산이 느려서 편성 조작이 끊기면 시뮬레이션 횟수를 줄이거나 입력이 멈춘 뒤에 계산한다. 어떻게 했는지 보고한다.

### 4. 테스트
- 같은 입력이면 같은 결과.
- 숨은 값만 다르고 보이는 정보가 같은 두 리프트는 같은 위험도가 나온다(새지 않음).
- 파티를 강하게 하면 단계가 한 방향으로만 바뀐다(단조성, 예: 레벨을 올리면 위험도가 나빠지지 않는다).
- 범위가 있으면 양 끝 중 더 나쁜 단계와 더 좋은 단계가 구간으로 나온다.
- 데이터 경계를 바꾸면 결과가 따라 바뀐다.
- 위험도 계산 전후로 세이브 상태와 실제 전투 결과가 같다.

### 5. 도구
- `npm run balance` 또는 별도 출력으로, 몇 가지 파티·리프트 조합에서 위험도 단계와 실제 승률이 얼마나 맞는지 표로 본다. 크게 어긋나면 보고한다. 수치 조정은 하지 않는다.

## 하지 않는 것
- 자동 편성이 위험도를 쓰게 하는 것, 리프트 목록 카드에 위험도를 붙이는 것은 이 지시서 범위 밖이다. 나중에 얹을 자리는 막지 않는다.
- 수치 조정(경계, 가중치)은 사용자의 플레이 이후에 정한다.
