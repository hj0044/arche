# 지시서 작성·수행 규칙

모든 지시서(`NNN-*.md`)는 아래 완료 조건을 포함한다. 지시서 본문에 따로 적지 않았어도 적용된다(AGENTS.md "구현 원칙", 사용자 확정 2026-11-23).

## 완료 조건 (필수)
1. 테스트·타입 검사·빌드가 통과한 PR을 연다.
2. 사용자 확인을 기다리지 않고 바로 `main`에 머지한다. 결정이 필요한 항목은 PR 본문과 `docs/open-questions.md`에 적되 머지를 막지 않는다.
3. Render 배포가 `live`가 된 것을 확인한다. 실패하면 고쳐서 다시 머지한다.
4. 최종 보고는 "배포 완료", 배포 커밋, 지시서가 요구한 보고 항목, 미해결 결정 목록이다.

## 지시서를 쓰는 쪽(Claude)의 의무
- 새 지시서의 마지막에 "완료 조건: 머지와 배포까지" 절을 반드시 넣는다.
- 지시서 전달 안내에서도 "머지·배포까지 끝낼 것"을 함께 말한다.
