## 결정성 — 검수 스크립트로 만든 실제 JSON 사용

- `npm run make-audit-save`로 생성한 v2 `/tmp/arche-audit-v2.json`을 사용했다. 같은 시드 `audit-20261120`으로 다시 생성한 파일은 바이트 단위로 같았다.
- JSON을 읽고 `r1`에 자동 편성 4인을 보낸 경우와, 그 편성에서 주인공을 제외한 3인을 보낸 경우를 각각 검증했다. 각 파견 직후 상태를 메모리 경로와 `createSaveFile → serializeSave → parseSave` 경로로 나누고, 10번의 `advanceDay`마다 상태 전체와 이벤트 배열을 깊은 비교했다. 두 경우 모두 10/10 일치했다. 전투 시드 `audit-20261120:x1`에서 각 쌍의 결과는 각각 3라운드 승리와 5라운드 승리였고 모두 11일차에 제로 455·아르케 82였다.
- `npm test` 10개 파일·120개 테스트와 `npm run build`(타입 검사 포함)가 통과했다. `npm run days -- 20 audit-20261120`을 두 번 실행한 출력도 바이트 단위로 일치했다. 새 출전 요약과 `npm run balance`의 4인 표본이 출력되는 것을 확인했다.

## 오류 — 심각도순

### 몬스터가 없는 리프트를 포함한 손상 v2가 가져오기에 성공한다

- 날짜: 2026-11-20
- 검수자: Codex
- 종류: 오류
- 심각도: 중간

#### 위치

`src/storage/saveSchema.ts:20–32, 113–115`, `src/storage/saveService.ts:92–95`, `src/engine/combat.ts:144–147`, `src/ui/screens/RiftList.tsx:30–40, 79–84`.

#### 설계서 근거

명세 §7·§9 [확정], 004-A §1 가져오기 검증. 정상 생성에서 리프트의 적 수는 데이터 표의 양수 범위 안이다.

#### 현상

`enemies`가 배열이면 빈 배열도 통과한다. 배포에서 가져오기에 성공하고 카드에 `LvInfinity~-Infinity`와 `제로 -∞`가 표시됐다. 해당 리프트에 파견하고 다음 날로 진행하면 ‘진행 실패: 적이 없다’가 표시됐다. 이는 1차의 필수 필드 누락과 별개로 남은 게임 상태 검증 문제다.

#### 재현 방법

- 시드: `audit-20261120`
- 세이브(JSON 또는 파일 위치): `npm run make-audit-save`로 만든 `/tmp/arche-audit-v2.json`의 사본. `state.rifts` 중 `id === "r1"`인 항목에 `"enemies": []`를 설정한다.
- 순서: 사본을 가져와 서울 `r1`에 편성·파견한 뒤 다음 날로 진행한다. 엔진에서 `parseSave → dispatch → advanceDay`로도 재현된다.

#### 제안

저장 스키마에서 몬스터 목록의 최소 개수를 검사하고, 슬롯 기록 전 `state.rifts[i].enemies` 경로를 표시한다. 리프트가 파견·보고에 포함되는 경로에도 같은 검증을 적용한다.

- 검수자: Codex
- 종류: UI·UX
- 심각도: 낮음

#### 위치

#### 설계서 근거

#### 현상

기본 새 게임은 본문 높이와 스크롤 높이가 모두 708px였다. 모드·이름 두 칸·시작 도시·접힌 세부 설정이 보였고 시작 버튼은 y=788~836px에 있었다. 소프트 키보드를 띄운 상태나 세부 설정을 펼친 상태는 이 판정 범위에서 제외했다. 모드·도시·세부 펼치기는 높이 44px 이상, 전열·후열은 53×44px, 후보 행의 추가·빼기 버튼은 높이 60~61px, 파견은 366×48px였다. 후보 한 명을 빼기 전후에 네 행의 y 좌표도 같았다. 재생 이전·다음은 48×48px이지만 속도 버튼은 35×48px로 너비 44px에 못 미쳤다.

#### 재현 방법

- 시드: 새 게임 화면은 시드 없이, 편성과 재생은 `audit-20261120`.
- 세이브(JSON 또는 파일 위치): `/tmp/arche-audit-v2.json`
- 순서: 새 게임 기본 화면의 본문과 하단 버튼을 측정한다. 고정 파일을 가져와 서울 `r1`에서 자동 편성 → 후보 마지막 행 제외 → 다시 자동 편성 → 파견 → 다음 날 → 전투 보기를 진행한다.

#### 제안

재생 속도 버튼에 최소 너비 44px를 적용한다.
