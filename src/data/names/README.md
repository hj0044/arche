# 계약자 이름 풀

`cultures.json`은 문화권 식별자, 한글 표시명, 지역, 인구(백만 명), 성과 이름의 순서, 한 사람에게 붙는 성의 개수 범위를 담는다. 문화권 식별자와 같은 이름의 파일에 성 60개와 이름 100개를 둔다. 성과 이름의 표기는 공백 없이 한글 1–8자다.

이름의 성별 표시는 `m` 남성, `f` 여성, `n` 중성이다. 표기마다 `modern` 현대적, `noble` 고전적, `rugged` 강인함, `gentle` 부드러움 중 한두 가지 인상을 붙인다.

|---|---|

## 배치 1 확인 자료

- 태국 이름과 성은 [태국 이름 말뭉치](https://github.com/korkeatw/thai-names-corpus)에서 사용례를, [태국 성씨 분포](https://forebears.io/thailand/surnames)에서 성씨의 빈도를 확인했다.
- 베트남은 [이름 표기와 성씨 관습](https://hnou.edu.vn/gai-vu-to-viet-nam-a7119.html), [중성 이름 목록](https://www.behindthename.com/names/gender/unisex/usage/vietnamese)을 참고했다.
- 인도네시아 가문명은 [가문명 표기 안내](https://perpus.ahmaddahlan.ac.id/app/uploads/2024/07/Pedoman-Penulisan-Daftar-Marga-Adat-dan-Gelar-Kebangsawanan-1.pdf)를 참고했다. 말레이시아 내부의 부칭과 성 표기 차이는 [말레이시아 외교부 안내](https://www.kln.gov.my/web/are_dubai/faqs)를 따랐다.
- 필리핀은 [필리핀 통계청 등록 이름 통계](https://psa.gov.ph/sites/default/files/infographics/Infographics_2024%20Most%20Common%20Baby%20Names-signed.pdf)와 [성씨 분포](https://forebears.io/philippines/surnames)를 참고했다.

## 배치 2 확인 자료

- 남인도의 중성 이름은 [타밀어 이름 목록](https://www.behindthename.com/names/gender/unisex/usage/tamil)과 [말라얄람어 이름 목록](https://www.behindthename.com/names/gender/unisex/usage/malayalam)을 참고했다. 파키스탄·방글라데시 중성 이름은 [우르두어 목록](https://www.behindthename.com/names/gender/unisex/usage/urdu)과 [벵골어 목록](https://www.behindthename.com/names/gender/unisex/usage/bengali)을 참고했다.
- 몽골 가문명은 [몽골 국가통계청의 성씨 자료](https://www.1212.mn/en/statistic/fun-statistic/family-name)를 참고했다. 중성 이름은 [몽골어 목록](https://www.behindthename.com/names/gender/unisex/usage/mongolian)과 [카자흐어 목록](https://www.behindthename.com/names/gender/unisex/usage/kazakh)을 참고했다.
- 서아시아와 북아프리카의 중성 이름은 [아랍어 목록](https://www.behindthename.com/names/gender/unisex/usage/arabic), [튀르키예어 목록](https://www.behindthename.com/names/gender/unisex/usage/turkish), [페르시아어 목록](https://www.behindthename.com/names/gender/unisex/usage/persian)을 참고했다.
