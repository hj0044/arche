# NPC 용병단 리그 데이터

`teams.json`은 용병단 식별자와 이름, 명단 구분, 소속 세력, 초기 규모, 리그 초기 배치 힌트, 거점 도시, 컨셉과 소개를 담는다. 거점 도시가 비어 있는 팀은 특정 도시에 묶이지 않는다. 설정 용병단은 14곳이고 민간 용병단은 25곳이다.

`featured.json`은 설정 용병단의 대표 인물을 담는다. 인물의 용병단 식별자는 `teams.json`, 문화권 식별자는 이름 풀의 `cultures.json`을 참조한다. 역할, 속성, 고향, 배경과 함께 직책, 한 줄 설정, 말투를 기록한다.

`rules.json`은 리그 규칙이다(지시서 028a). 등급 5개(팀 수·승강 수·시즌 목표 점수·난수 폭·활약도 기준), 리그 힌트를 등급으로 바꾸는 표, 규모 단계 5개(인원 범위·개인 계수·상위 강자 수), 시즌(60일, 간이 정산 15·30·45일, 이력 5시즌), 점수 곡선, 시즌 변동 확률, 민간 용병단 새 이름 재료, 이름 생성기 설정(문화권 가중치·상한·대륙 최소·띄어쓰기·NPC 고향 도시)을 담는다. 수치는 임시값이다.
