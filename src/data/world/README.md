# 도시 확장 데이터

- `cities.json`은 서울, 도쿄, 뉴욕과 새 도시 여섯 곳의 표시 문구, 개방자 상대 비율, 리프트 생성, 영입 값을 담는다. 기존 세 도시의 행에는 설정 문구와 개방자 비율을 추가했다.
- `travel.json`은 서로 다른 도시 사이의 노선 36쌍을 왕복 총 일수로 담는다. 순서에 관계없이 한 쌍을 한 번만 기록한다. 0일은 당일 왕복이고, 1일은 왕복에 하루를 배정한다는 뜻이다.
- `influence.json`은 세력별로 각 도시에서 인물이 등장하는 상대 가중치다. 각 세력의 가중치 합은 1이다.

## 수치 기준

- 라고스, 뭄바이, 상파울루는 리프트 한도와 일일 생성 시도 수를 높였다. 라고스의 개방자 비율이 가장 높고, 뭄바이의 타향 영입 배율은 뉴욕과 같은 최솟값이다.
- 런던은 생성 압력을 중간 정도로 두었다. 두바이는 관문 비율이 높고 항로가 드물며, 시드니는 항로 비율이 가장 높다.
- 이동은 기존 세 노선을 유지했다. 나머지는 도시 중심 간 대권 거리로 순위를 매겨 먼 노선 열 곳에 하루를 배정했다. 이 순위에서 시드니 노선은 항만 보급의 이점을 반영해 약 천오백 킬로미터를 뺐다. 이 보정값은 노선을 정하는 데만 사용했다.
- 세력 영향력의 분포는 세계관 요약의 주요 활동 도시를 따른다. 여러 곳에서 활동하는 에지 서클에는 고른 가중치를 두었다.

## 제안 설정

- 아르케 고속 수송과 개방자의 이동 능력 지원으로 먼 도시도 하루 안에 왕복할 수 있다.
- 안정화된 항로와 연계한 보급망을 갖춘 시드니는 일부 장거리 노선도 당일 왕복이 가능하다.

## 열린 질문

- 당일 왕복권을 지리적 지역권과 별개로 볼까요? 1일 노선 최대 열두 쌍을 맞추려면 대륙을 가로지르는 노선 일부도 0일이어야 한다.
- 시드니의 이동 이점은 항만 보급과 수송 연계로 설명할까요? 항로를 통한 도시 간 환승도 설정에 포함할지 확인이 필요하다.
- 세계관 요약의 도시색은 제안이고 D04의 도시색은 확정이다. 세계관 요약의 상태를 D04와 일치시킬지 확인이 필요하다.
